Privacy policy

Last updated: 9 November 2026

Marketing MCP is a private tool used only by its owner, Đani Peršić (Emerald Agency, Centar 307, 52203 Medulin, Croatia), to access his own Google accounts.

What data it accesses

With the owner's consent it reads Gmail messages and attachments, reads and writes Google Drive files, creates Gmail drafts, and reads Google Analytics, Tag Manager and Ads data, all in the owner's own accounts.

How the data is used

Data is used only on the owner's own computer to prepare bookkeeping documents and marketing reports. It is not sold, shared with third parties, or used for advertising. Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.

Storage and deletion

Access tokens are stored locally on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.
